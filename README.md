# FitIA-Frontend

Este repositório contém a **versão inicial do front-end** do FitIA Dashboard, desenvolvido em **HTML, TailwindCSS e JavaScript**.  
O objetivo é estruturar e validar as páginas antes da implementação do **back-end** e da futura migração para **React**.

---

## 🚀 Status  
✅ Versão Front-end concluída  
🔧 Próximas etapas: Integração com back-end + migração para React

---

## 📂 Estrutura de Páginas  
- **index.html** – Página inicial  
- **login.html** – Tela de autenticação  
- **students.html** – Gestão de alunos  
- **students-risk.html** – Risco de evasão  
- **students-comms.html** – Comunicação com alunos  
- **reports.html** – Relatórios  
- **finance-*** – Páginas financeiras (caixa, planos, pagamentos, despesas, descontos)  
- **settings.html** – Configurações  
- **trainings.html** – Treinos  
- **assistant.html** – Assistente IA  

---

## 🎯 Objetivo  
Construir um **painel administrativo moderno e funcional** para academias, que será integrado a um sistema de **IA para previsão de cancelamentos** e **gestão inteligente de alunos**.

---

## 🛠️ Tecnologias Utilizadas  
- **HTML5**  
- **TailwindCSS**  
- **JavaScript (Vanilla)**
